# Sistema de Gestión de Turnos y Listas de Espera - Centro de Salud Periurbano

## Descripción del Proyecto
Este repositorio contiene la planificación y documentación para el desarrollo de un Producto Mínimo Viable (MVP) enfocado en un Sistema de Apoyo a la Decisión (DSS). El sistema organiza los turnos de atención, calcula el tiempo estimado de espera y prioriza a los pacientes según su nivel de urgencia.
